# خريطة سوريا التفاعلية

صفحة واحدة (One Page) بتصميم سينمائي: خلفية سوداء بالكامل، وخريطة سوريا
تظهر تدريجيًا من العدم كحدود خضراء متوهجة (Neon/Emerald) عائمة في الفراغ،
مع توهج تنفّسي خفيف وحركة طفو مستمرة.

## الملفات

- `index.html` — البنية + SVG الخريطة (مضمّن داخل الصفحة)
- `style.css` — نظام التصميم كاملاً: الألوان، الحركات (Fade In / Glow / Float / Breathe)، والتجاوب
- `script.js` — تأثير Parallax خفيف جدًا يتبع المؤشر (يُعطَّل تلقائيًا على الجوال ومع إعداد "تقليل الحركة")

## التشغيل محليًا

لا حاجة لأي بناء (build) — الموقع HTML/CSS/JS خالص:

```bash
# أي خادم ثابت يفي بالغرض، مثال:
npx serve .
# أو
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080` (أو المنفذ الذي يعرضه الخادم).

## النشر

الملفات الثلاثة ثابتة بالكامل ويمكن نشرها مباشرة على أي مضيف ثابت:
Vercel، Netlify، GitHub Pages، Cloudflare Pages، إلخ. فقط ارفع محتويات
هذا المجلد كما هي.

## ملاحظة حول دقة الخريطة

حدود سوريا هنا عبارة عن تبسيط هندسي (SVG path) مبني على الإحداثيات
الجغرافية الفعلية لحدود البلاد (خط الساحل، الحدود مع تركيا/العراق/الأردن/
فلسطين المحتلة/لبنان)، وليست صورة نقطية. الشكل مقارب بدرجة عالية للشكل
الحقيقي، لكنه مبسّط (عدد نقاط محدود) لأغراض الأداء والوضوح البصري في هذا
التصميم السينمائي؛ وليس بديلاً عن خريطة مساحية دقيقة.

## التخصيص السريع

- **اللون**: غيّر `--emerald` في `style.css` (والمتغيرات المشتقة منه) لأي درجة أخرى.
- **سرعة الظهور**: عدّل `--dur-map-in` / `--dur-glow-in` / `--dur-caption`.
- **النص السفلي**: عدّل محتوى `.caption-title` و `.caption-sub` في `index.html`.
